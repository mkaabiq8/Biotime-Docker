# BioTime installation media

Do not commit the licensed BioTime installer or license files to a public Git
repository. Copy your legitimate installer into this directory directly on the
VPS. It appears as the `Z:` drive / `Shared` folder in Windows.

The deployment expects the security-fixed Middle East build **8.5.5.2944** or a
newer build that ZKTeco has confirmed contains the fix for CVE-2023-38950 and
CVE-2023-38951.
